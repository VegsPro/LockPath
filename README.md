# LockPath

Android app locker with password protection for selected applications.

## Features

- Master password for the app itself
- List of all installed apps
- Per-app: enable protection, shared or unique password
- Numeric keypad option (like Telegram)
- Language switch (RU / EN)
- Disguise mode (appear as Calculator, Settings, Notes, Gallery, Chrome)
- Accessibility Service based locking

## Setup after install

1. Open LockPath and create master password
2. Go to Settings → enable Accessibility Service for LockPath
3. Optionally grant overlay permission if prompted
4. Select apps to protect and set passwords

## Build

Signed release APK is built automatically via GitHub Actions on push to `main`.
